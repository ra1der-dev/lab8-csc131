# Dev notes

One file per change. The name is the sort order:

`YYYY-MM-DD-HHMM-short-title.md`

Example: `2026-10-24-1433-save-prompt-yn.md`

- `YYYY-MM-DD` is the date.
- `HHMM` is the 24-hour local time, so `1433` is 2:33 PM.
- `short-title` is a few lowercase words separated by hyphens.

Sort the folder by name, A to Z, for the oldest change first. Sort by name, Z to A, for the latest change first. The date stays readable as the list gets long.
