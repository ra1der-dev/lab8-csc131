# AGENTS.md

Project: Lab 8, CSC 131 (UNCW). A beginner Python text dungeon game in one file, `app.py`, themed on World of Warcraft (Horde).

Rules and design live in `.cursor/rules/`:
- `lab8-rules.mdc` - hard rules from the lab. Always apply.
- `game-design.mdc` - how the hero, monsters, loot, and save file work.

How to test:
1. `python check_lab.py` (from Canvas; must show 21/21).
2. Play: (N)ew game, fight a few times, 5 to view loot, 3 to save, 4 to quit.
3. Run again, choose (C)ontinue, check that HP, XP, gold, weapon, and loot bag came back.

`check_lab.py` is not in this repo. Download it from Canvas into this folder.
